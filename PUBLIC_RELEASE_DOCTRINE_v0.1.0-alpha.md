## Historical purpose

This record was created while resolving the conflict between the earlier controlled-distribution architecture and the intended first public TEBDLC Release Candidate.

It recorded the decision that `Release-Candidate-v0.1.0-alpha-TEBDLC` should contain a complete, usable and verifiable public TEBDLC Release Candidate, including the material required for operation and independent verification: selected source code, build components, tests, vectors, evidence, documentation and reproducibility resources.

## Preservation rule

Supersession of a publication model does not automatically invalidate unrelated historical facts, validation results, provenance records, intellectual-property notices, hashes, test results or evidence. Each remains evidence of the state it actually describes.

No historical document, validated gain, evidence record or source component is to be deleted merely because the publication doctrine changed.
