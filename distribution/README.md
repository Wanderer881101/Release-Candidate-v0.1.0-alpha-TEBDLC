# Controlled-distribution subsystem — historical/R&D status for v0.1.0-alpha public release

**Jonathan Therrien, Marieville, Québec.**

The files in this directory are preserved because they document and implement a substantial controlled-distribution experiment: authentication, authorization, territorial resolution, private package assembly, controlled delivery, audit logging, clean-room verification and adversarial validation.

For the **first public TEBDLC `v0.1.0-alpha` Release Candidate**, this subsystem is **not the active publication boundary**.

The active release model is `../ACTIVE_RELEASE_MODEL_v0.1.0-alpha.md`.

Accordingly:

- the public Release Candidate may contain the complete intentionally selected usable product;
- this directory does not make publicly published source private or territorially inaccessible;
- references here to a private package vault, controlled complete source, or the public GitHub repository containing no complete source describe the earlier controlled-distribution architecture and are retained as historical/R&D material;
- the subsystem may remain useful for future private artifacts, controlled services or later explicitly versioned distribution models;
- historical test results and proofs for this subsystem remain valid as evidence of what was tested; they are not automatically evidence for the active public-release boundary.

Nothing in this notice deletes or rewrites the earlier work. It establishes how this directory is to be interpreted in the public `v0.1.0-alpha` Release Candidate.
